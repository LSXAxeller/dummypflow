# ProseFlow v0.2.0 - Enhanced Model Management

This release focuses on improving the local model management experience, providing users with better feedback, stability, and control over their on-device AI.

## ✨ New Features

- **Missing Model Detection**: The "My Models" library now automatically detects if a model's file has been moved or deleted from your disk.
    - Missing models are clearly marked with a warning icon and a descriptive tooltip.
    - Users can now **Relocate** a missing model by pointing ProseFlow to its new file location, or **Remove** the invalid entry.
- **Hardware Resource Warnings**: When selecting a local model in the Providers settings, ProseFlow will now display a real-time warning if the model's size exceeds your available system RAM or VRAM. This helps prevent performance issues and application instability.
- **Enhanced Local Model Actions**: The UI for managing local models has been improved with dedicated buttons for "Relocate" and "Remove" when a model file is missing, clarifying the user workflow.

## 🐛 Bug Fixes & Improvements

- **UI**: Added a `Status` column to the "My Models" table for better visibility of model state.
- **UI**: Rows for missing models are now visually de-emphasized to draw attention to them.
- **Backend**: The `LocalModelManagementService` is now responsible for checking file existence, centralizing the validation logic.
- **Backend**: The `ProvidersViewModel` now integrates with the `HardwareMonitoringService` to provide live resource availability data.

This update makes managing a local model library more robust and user-friendly. As always, please report any bugs or feature requests on our GitHub Issues page.
